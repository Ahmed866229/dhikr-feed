# Dhikr RSS Feed

ده ملف RSS بيحتوي على مجموعة من الأذكار اليومية، تقدر تستخدمه مع بوتات زي Manybot على تليجرام أو أي تطبيق بيدعم RSS feeds.

## طريقة الاستخدام

1. انسخ الرابط المباشر للملف `dhikr_feed.xml`.
2. ضيفه في البوت أو التطبيق اللي بتستخدمه.
3. استمتع بالتذكير اليومي بالأذكار.

**ملحوظة:** لازم يكون الرابط مباشر (زي raw.githubusercontent.com) علشان يشتغل.
